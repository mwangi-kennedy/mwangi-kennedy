##  About Me

###  Who I Am
I am an Information Technology graduate from Dedan Kimathi University of Technology who operates at the intersection of robust backend engineering, intelligent systems and user-centered interaction design. I don’t believe developers should be confined to a single layer of the stack; instead, I specialize in bridging the gap between heavy technical execution, like deploying on-device AI pipelines and crafting high-fidelity, intuitive UI/UX systems in Figma.

###  Leadership & Project Philosophy
As a former Product Development Team Lead at the Guild Code Community, I developed a collaborative, engineering-first approach to project execution. I excel at translating complex feature requirements into structural user journeys and optimized developer handoffs. I believe that clean version control, comprehensive technical documentation and rapid, iterative debugging are just as critical to a product's success as the code itself.

###  What Drives Me
* **Community-First Innovation:** I am deeply committed to building technology that solves immediate, real-world challenges facing African communities, whether that means architecting secure, privacy-focused social accountability platforms or engineering proactive environmental monitoring systems.

* **Fluid User Experiences:** I treat interfaces as living ecosystems, ensuring every administrative panel, transaction flow, and mobile dashboard is accessible, responsive and completely friction-free for the end-user.

###  Beyond the Terminal
When I am not tracing server logs, training models or structuring design systems, you will find me pushing my limits out on the road as an avid long-distance cyclist, deep into a book, or exploring the next frontier of tech automation.

##  Featured Projects

###  Route Weather AI Optimizer
A high-capacity full-stack transit telemetry and meteorological risk panel engineered to map custom transportation corridors across Kenya, evaluate regional micro-climates, and alert transit operators to highway atmospheric hazards in real time. Shifting focus from single-point lookup to corridor-based monitoring, it serves as an automated safety layer for fleets and cyclists.
* **Key Solutions:** Optimized 10MB data ingress middleware to handle large raw GIS polyline paths; engineered an asynchronous data-reduction loop to downsample complex paths into 8 key waypoints; implemented an accumulating staggered sleep multiplier delay ($index \times 80\text{ms}$) to bypass upstream 429 API rate limits.
* **Tech Used:** Node.js, Express.js, React.js (Vite), Leaflet, OpenStreetMap API, Axios, Custom SVG Renderers

---

###  Optic Nerve — Image-to-Text Recognition System
A production-quality, end-to-end computer vision pipeline that detects and extracts structured text from natural scene images using deep learning OCR, systematic image pre-processing adjustments, confidence filtering, and spatial suppression algorithms.
* **Key Solutions:** Built a 9-stage conditioning pipeline integrating Grayscale conversion, Gaussian blurring for noise reduction, Adaptive Thresholding for uneven lighting, and Morphological Dilation; utilized EasyOCR (CRAFT + CRNN models) alongside Non-Maximum Suppression (IoU $\le$ 0.30) to eliminate duplicate bounding box detections.
* **Tech Used:** Python, EasyOCR, OpenCV, NumPy, Matplotlib, Pillow, Google Colab

---

###  BridgeForce — Secure Social Accountability Platform
An intelligent mobile architecture built for real-time media pipeline analysis and secure reporting metrics. Designed intuitive, lightweight user onboarding layouts and micro-interaction flows in Figma, backed by robust on-device AI/ML validation models to enforce data anonymity and platform trust.
* **Tech Used:** Android Architecture, Python, AI/ML, Computer Vision, Figma UI/UX, TensorFlow Lite

---

### Skill-to-Role Matching Engine
A content-based filtering recommendation engine that ingests user tech-skill profiles and returns mathematical alignment metrics matching them against 20 predefined industry career paths.
* **Key Solutions:** Implemented TF-IDF text vectorization to properly reward rare, specific skills while penalizing generic keywords; utilized Cosine Similarity over Euclidean metrics to accurately evaluate profile alignment based on vector angle orientation independent of vector magnitude variations.
* **Tech Used:** Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebooks

---

### ₦ Nigerian Naira Image Classification System
A robust deep learning system engineered to classify the eight circulating denominations of the Nigerian Naira (₦5–₦1000). Built using a custom 4-block CNN architecture in TensorFlow, focused heavily on model optimization, data augmentations, and handheld mobile device image capture performance.
* **Tech Used:** TensorFlow, Keras, CNNs, Python, Deep Learning, Data Analytics
