##  Featured Projects

###  AI-Powered Protest Intelligence System
An intelligent mobile application that analyzes protest media input using AI and generates detailed reports, including automated flagging to relevant authorities when necessary.

**Tech Used:** Python, AI/ML, Computer Vision, Data Analysis, Tensorflow

---

###  Nigerian Naira Image Classification System
A robust image classification system for the eight circulating denominations of the Nigerian Naira (₦5–₦1000), built using a custom 4-block CNN architecture in TensorFlow.

Focused heavily on analytics-first optimization and real-world handheld mobile image capture performance.

**Tech Used:** TensorFlow, CNNs, Python, Deep Learning, Data Analysis

---

###  Early Flood Detection & Warning System
A collaborative intelligent system focused on proactive flood monitoring, environmental analysis, and early warning generation to help vulnerable communities respond faster.

**Tech Used:** AI/ML, Data Analysis, Monitoring Systems, APIs
